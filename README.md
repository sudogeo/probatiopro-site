# probatiopro.fr

The public vendor site for **Probatio Pro**, published with GitHub Pages at
<https://probatiopro.fr>.

It holds two pages and nothing else:

| Path | What it is |
|---|---|
| `/` | What *Access Certification for Jira* does, and how to reach support |
| `/privacy` | The privacy policy for that app |

This repository is public because everything in it is meant to be read by anyone. The
application's source code lives in a separate, private repository.

Changes to the privacy policy carry a version number and an effective date on the page itself;
material changes are described there rather than absorbed silently.

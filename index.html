Probatio Pro

Access Certification for Jira

Periodic user access reviews, run inside Jira Cloud, producing evidence an auditor can test rather than take on trust.

What it does

It reads your permission schemes, project roles and group membership, then asks Jira what each account can actually do — and reports where the two disagree. A right that exists but that no grant explains is a finding, not a silence.

Every right carries the reason it is held, in a sentence a reviewer can act on: who, through which group, mapped to which role, granted by which scheme.

Each review is sealed as a dated snapshot with a content hash. A recipient can recompute that hash from the exported file alone, without this app — which is what makes the evidence testable instead of merely asserted.

It never changes anything in Jira. Every permission the app requests is a read permission: it cannot grant, revoke or modify a right, by design rather than by policy.

Nothing leaves Atlassian. The app makes no network call outside Atlassian's own infrastructure, uses no analytics and no third-party service, and qualifies for Atlassian's Runs on Atlassian programme.
